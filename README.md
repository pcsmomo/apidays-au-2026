# apidays Australia 2026 Grid

An unofficial, phone-friendly grid of the [apidays Australia 2026](https://www.apidays.global/events/australia#agenda) agenda (28–29 Oct 2026, MCEC Melbourne). Rooms are columns and time runs down the side, so you can see what's on in every room at once.

**Live page:** https://pcsmomo.github.io/apidays-au-2026/

- Day 1 / Day 2 tabs, with times in AEDT
- Session blocks sized to their real length, colour-coded by co-located event (Apidays, Cloud Native Summit, API Economy Summit, Executive AI Security Forum, GraphQL Day)
- Tap a session for the full abstract and speaker details
- Search by topic, speaker or company
- Star sessions to build your own schedule (saved in your browser only)
- A "now" line during the event

The session data is a snapshot of the official agenda taken on 27 Oct 2026. Rooms and times can change, so check the [official agenda](https://www.apidays.global/events/australia#agenda) on the day. This page is not affiliated with apidays.

It's a single static `index.html` with no build step.
